Why Switzerland Uses CH and CHF

A small note on why Switzerland's country code and currency code look Latin rather than English.

Switzerland's internet domain is .ch, and its currency is written as CHF, but neither starts with the English word "Switzerland".

The CH comes from Confoederatio Helvetica, the Latin name for the Swiss Confederation. Latin is useful here because Switzerland has German, French, Italian, and Romansh as national languages, so it avoids choosing one language over the others.

CHF follows the same logic. In the ISO currency code, CH identifies Switzerland and F stands for franc. So CHF is basically "Switzerland + franc" compressed into three letters.

Small distinction: people often remember CHF as Confoederatio Helvetica Franc. That is a useful shortcut, but the technical ISO explanation is even simpler: country code CH plus F for franc.

It is one of those tiny naming choices where politics, language, and standards quietly meet each other.

Where this comes from
